# Local typefaces

Served from this site so the interface does not depend on a connection to Google Fonts.

- Fraunces 500 regular and italic — editorial headings and index numerals.
- DM Sans 400, 500, 600, 700 — interface, body text and numerical counters.
- Noto Serif SC 600 — a small subset for the authored Chinese display headings only. User content and form labels retain the system sans-serif stack.

Font files were obtained from the official Google Fonts CSS API on 2026-11-11. Each family includes its upstream SIL Open Font License from https://github.com/google/fonts/tree/main/ofl. The CJK subset contains the characters in `安全研究工作区设计工作台研究总览项目档案论文库研究日历研究工具研究工作流`; additional display headings should extend the subset or fall back to a system serif.
